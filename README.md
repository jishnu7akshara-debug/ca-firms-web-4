# Finora Advisors — CA / CS / tax firm website (version 4, reviewed intern build)

Double-click `index.html` to open. Fonts, photos and scripts are stored locally, so it works offline.

```
index.html          all six views (Home, Services, Engagement, Resources, About, Contact) — hash-routed
assets/css/style.css
assets/js/main.js   router, scroll reveals, GST calculator, form validation
assets/fonts/       Sora, DM Sans (woff2)
assets/images/      7 photos (Unsplash licence)
```

Placeholders to replace before launch: firm particulars (years, team size, partners), address/phone/email, WhatsApp number.
Connect the contact form (`#cf` in main.js) to a backend or email service.
